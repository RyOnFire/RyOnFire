### 🚀 Key Projects

#### 📌 Kickstarter Crowdfunding Recommendation Engine — *Break Through Tech AI Studio, Fall 2026*
A team project, built with an industry Challenge Advisor, that predicts whether a Kickstarter campaign will succeed, explains what drives those predictions, and recommends changes for campaigns at risk of failing. Trained on 38,504 U.S. campaigns.
- Compared five classifiers (Logistic Regression, Random Forest, KNN, XGBoost, LightGBM) on a shared train/test split; selected tuned **XGBoost** with **81.4% accuracy and 0.898 ROC-AUC**
- Identified and documented data leakage risks, and reported results with and without a potentially leaky feature (`updates`)
- **My contributions:** dataset acquisition and filtering, goal and engagement EDA, XGBoost and LightGBM models, final model comparison and selection, the recommendation prototype, and the Streamlit front end
- **Tech:** Python, Pandas, scikit-learn, XGBoost, LightGBM, SHAP, Streamlit
- 🔗 [GitHub Repo](https://github.com/Break-Through-Tech/Global-Financial-Firm-1A-kickstarter-crowdfunding-recommendation-engine)

#### 💳 Fraud Detection Dashboard
A machine learning web app that detects credit card fraud on 284,807 real transactions, comparing **XGBoost** and **Random Forest** to handle a severe 0.17% fraud rate while achieving **99% precision**. Includes a fallback pipeline that trains a custom model on any user-uploaded dataset.
- **Tech:** Python, Pandas, scikit-learn, XGBoost, SMOTE, Streamlit, Plotly
- 🔗 [GitHub Repo](https://github.com/RyOnFire/fraud-detection) · [Live App](https://fraud-detection-dashboard.streamlit.app)

#### 📊 Credit Risk Dashboard
A credit default prediction system trained on 121,000+ cleaned borrower records, using **Logistic Regression** and a **feedforward neural network** with SMOTE oversampling to better detect high-risk borrowers in an imbalanced dataset. Deployed with configurable probability thresholds and exportable reports.
- **Tech:** Python, Pandas, scikit-learn, PyTorch, SMOTE, Streamlit, Plotly
- 🔗 [GitHub Repo](https://github.com/RyOnFire/credit-risk) · [Live App](https://credit-risk-dashboard.streamlit.app)
