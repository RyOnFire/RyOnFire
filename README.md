### 🚀 Key Projects

#### 📌 Panther Pulse — *Break Through Tech Sprinternship™, FIU IT Department*
A real-time endpoint detection and vulnerability management dashboard built on **Splunk** and the **CrowdStrike Falcon Platform**. Co-built during a 3-week Sprinternship to give FIU's security analysts a single view of endpoint health, identity events, and vulnerabilities.
- Engineered a data pipeline correlating CrowdStrike Falcon sensor data within Splunk for indexing, correlation, and visualization
- Enabled analysts to prioritize alerts, identify high-severity vulnerabilities, and track endpoint compliance across FIU's network
- **Tech:** Splunk, CrowdStrike Falcon

#### 💳 Fraud Detection Dashboard
A machine learning web app that detects credit card fraud on 284,807 real transactions, comparing **XGBoost** and **Random Forest** to handle a severe 0.17% fraud rate while achieving **99% precision**. Includes a fallback pipeline that trains a custom model on any user-uploaded dataset.
- **Tech:** Python, Pandas, Scikit-learn, XGBoost, SMOTE, Streamlit, Plotly
- 🔗 [GitHub Repo](https://github.com/RyOnFire/fraud-detection) · [Live App](https://fraud-detection-dashboard.streamlit.app)

#### 📊 Credit Risk Dashboard
A credit default prediction system trained on 121,000+ cleaned borrower records, using **Logistic Regression** and a **feedforward neural network** with SMOTE oversampling to better detect high-risk borrowers in an imbalanced dataset. Deployed with configurable probability thresholds and exportable reports.
- **Tech:** Python, Pandas, Scikit-learn, PyTorch, SMOTE, Streamlit, Plotly
- 🔗 [GitHub Repo](https://github.com/RyOnFire/credit-risk) · [Live App](https://credit-risk-dashboard.streamlit.app)
